## Other products and their names

This project is not connected with Kenwood, VARA, VarAC or any other product it names. It does not
endorse them, and it is not endorsed by them. The names belong to their owners, and are used here
only to say what these tools work with.

- **Kenwood** makes the TM-D750. This project is written by a user of the radio, not by its maker.
- **VARA** is proprietary software. It is not free software. No part of it is included here, and
  d750ctrl does not need it.
- **xara** is what the `d750 vara` verbs talk to. It is a separate program, written independently,
  that speaks a protocol compatible with VARA's. It is not VARA, and it has its own license. It is
  not part of this project.
- **VarAC** is a separate chat program by its own authors. This project only sends frames in the
  form that VarAC stations expect.

See [VARA, xara and chat](vara-and-chat.md) for how these fit together.
